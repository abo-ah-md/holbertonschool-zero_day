# holbertonschool-zero_day

This is my first repository as a full-stack engineer, created as part of the Holberton School curriculum.

## Project Overview

This repository serves as an introduction to source code management using Git and GitHub. It is structured to teach you the fundamentals of version control, collaborative coding, and best practices for managing codebases.

### Key Concepts Addressed

- Source code management fundamentals
- Difference between Git and GitHub
- Creating and cloning repositories
- Writing clear and helpful README files
- Staging, committing, and pushing code
- Creating and handling branches
- Resolving merge conflicts
- Collaborative workflows on GitHub
- Proper use of `.gitignore`
- File management and repository hygiene

### Directory Structure

- `git/` — Contains subprojects and tasks related to Git/GitHub training
  - `bash/` — Bash scripting tasks
  - `c/` — C language tasks
  - `.gitignore` — Rules to prevent unwanted files from being tracked
  - `README.md` — Project-specific documentation
